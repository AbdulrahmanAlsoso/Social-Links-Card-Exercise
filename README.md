# Social-Links-Card

A simple **Social Links Card** built using only **HTML** and **CSS**.

This project displays a personal profile picture, name, and a list of social media links (such as Instagram, WhatsApp, GitHub, LinkedIn, etc.) in a clean and modern card design.  
It can be used as a personal portfolio card, contact page, or as a landing page for your bio links.

## ✨ Features
- Clean and modern UI.
- Profile picture with circular border.
- Hover effects for social links.
- Easy to customize colors, fonts, and links.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Flexbox, animations, hover effects)
